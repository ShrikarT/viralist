# Preserve a scene-local simulation evidence boundary

Viralist will expose sequential synthetic viewing, evidence-backed editing notes and explicitly uncalibrated scenario ranges; it will not use whole-video prompts per persona or label those ranges as real-world prediction confidence. Whole-video scoring is simpler, but makes post-skip isolation unprovable and undermines the proposed differentiator; separating the stored feature bundle from a strictly scene-local input projection preserves that boundary. This proposal formalizes the supplied no-accuracy mandate; empirical calibration remains a distinct future product decision.
